# Cojudge Homebrew Tap

Official tap for the Cojudge desktop app (macOS).

```bash
brew tap cojudge/tap
brew install --cask cojudge
```

Or in one line without tapping first:

```bash
brew install --cask cojudge/tap/cojudge
```

Upgrades (including auto-updated apps) :

```bash
brew upgrade --cask cojudge
```

Casks are updated automatically by the `homebrew-tap` job in `cojudge/cojudge`'s `release-desktop.yml`.
